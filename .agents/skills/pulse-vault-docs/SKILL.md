# Документация Pulse в vault

Работай только в Rust-треке vault:

```text
/Users/vyutilikov/Library/Mobile Documents/iCloud~md~obsidian/Documents/CommonIcloud/Rust
```

## Порядок работы

1. Полностью прочитай `Rust/AGENTS.md`.
2. Прочитай целевой документ и документы, от которых зависит его смысл. Не загружай весь vault без необходимости.
3. Определи, относится информация к продуктовой документации vault или к инженерной документации репозитория.
4. Проверь факты по репозиторию, командам или сведениям пользователя. Не заполняй фактический результат этапа по планам и намерениям.
5. Измени файлы только при прямом запросе. Для проверки или вычитки сначала перечисли замечания и дождись отдельного запроса на правки.
6. После изменения проверь ссылки, нумерацию, термины и отсутствие противоречий с соседними документами.

## Правила содержания

- Сохраняй назначение каждого файла и существующую структуру каталога.
- Не создавай новые файлы или каталоги, если запрос можно выполнить в существующем документе.
- При изменении определения значимого термина проверь `Pulse/01 - Словарь терминов.md` и обнови его, если запрос охватывает эту правку.
- Разделяй факты, гипотезы, допущения, планы, модельные события и фактические события.
- Не добавляй архитектуру, технологию или код, если пользователь просит только описание проекта или этапа.
- Пиши естественным техническим русским языком. Удаляй повторы и текст без практической функции.

## Границы

- Не меняй код и файлы репозитория в рамках этого скилла.
- Не редактируй другие треки vault.
- Не копируй эксплуатационную документацию из репозитория в vault без отдельной причины.
- Если vault недоступен в текущей среде, сообщи об этом. Не создавай локальную копию вместо него.

В результате перечисли изменённые файлы и кратко укажи, какие факты или решения в них зафиксированы.
