# GitHub-поток Pulse

Репозиторий: `Isotere/pulse`. Основная ветка: `master`. GitHub Project: `Isotere`, project № 4.

Используй `git` для локального состояния и `gh` для GitHub. Не выводи и не сохраняй токены.

## Общие проверки

Перед изменением:

1. проверь `git status --short --branch`;
2. проверь remote и текущую ветку;
3. прочитай issue через `gh issue view`;
4. остановись, если незакоммиченные изменения могут потеряться или попасть не в ту задачу;
5. не откатывай пользовательские изменения.

Read-only проверка не разрешает менять GitHub. Ветка, push, PR, review, изменение полей Project, закрытие issue и merge требуют прямого запроса на соответствующее действие.

## Создание ветки под issue

При прямом запросе создать ветку:

1. определи номер issue и короткое имя;
2. убедись, что base — `master`, если пользователь не указал другую ветку;
3. предпочитай команду `gh issue develop`, чтобы связать ветку с issue;
4. используй имя `issue-<номер>-<краткое-название>`;
5. переключись на созданную ветку и покажи итоговый статус.

Не меняй статус или итерацию элемента GitHub Project, если пользователь не попросил об этом отдельно.

## Создание pull request

При прямом запросе создать PR:

1. проверь, что текущая ветка не `master`;
2. изучи diff и commits относительно base;
3. запусти относящиеся к изменению проверки, если они настроены;
4. не исправляй найденные ошибки без отдельного запроса;
5. если есть незакоммиченные изменения, не создавай commit автоматически: сообщи, что мешает подготовке PR;
6. отправь ветку в `origin`, если push входит в запрос на создание PR;
7. создай PR с понятным заголовком, описанием результата и выполненных проверок;
8. добавь `Closes #<номер>` в описание PR;
9. покажи URL и состояние проверок.

Соглашение:

```text
Ветка:  issue-<номер>-<краткое-название>
Commit: <type>: <изменение> (#<номер>)
PR body: Closes #<номер>
```

Не выполняй merge и не закрывай issue вручную. Не отправляй approve собственному PR. Сбой сети или авторизации не обходи альтернативной публикацией: сообщи точную причину.
