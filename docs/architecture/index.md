# Архитектура

Архитектура Pulse развивается вместе с наблюдаемыми обязанностями. Репозиторий
не содержит пустых компонентов и абстракций для предполагаемых будущих задач.

## Текущая структура

```text
pulse/
├── Cargo.toml
├── rust-toolchain.toml
├── apps/
│   └── market-inspector/
└── docs/
```

Корневой `Cargo.toml` описывает виртуальный Cargo workspace без корневого
package. `apps/market-inspector` — отдельный binary package и будущая точка входа
инспектора рыночных данных.

## Правила развития

- Исполняемые и развёртываемые компоненты размещаются в `apps/`.
- Библиотеки с устойчивой ответственностью размещаются в `crates/` после
  появления практической потребности.
- Приложения могут зависеть от библиотек; библиотеки не зависят от приложений.
- Каталоги, crates и инфраструктурные инструменты не создаются заранее.
- Фактическая инженерная и эксплуатационная документация хранится в этом
  репозитории.
