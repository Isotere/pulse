# Эксплуатация

У Pulse пока нет развёртываемых сервисов и production-окружения. Текущий
эксплуатационный контур ограничен локальной сборкой и просмотром документации.

## Локальная документация

Команда `make docs-build` выполняет строгую сборку в каталог `site/`. Каталог
содержит производный артефакт и не хранится в Git.

Команда `make docs-serve` запускает сервер разработки по адресу
`http://127.0.0.1:8000`. Этот сервер предназначен только для локального
просмотра.

## Отложенные задачи

В текущий контур не входят:

- публикация документации;
- Docker и Kubernetes;
- мониторинг и резервное копирование;
- production-конфигурация;
- доступ к реальной торговле.

Эксплуатационные разделы будут расширяться вместе с первым компонентом, которому
понадобится развёртывание или восстановление.
